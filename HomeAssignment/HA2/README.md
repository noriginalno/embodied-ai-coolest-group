## Воспроизведение

Из корня репозитория; проверено на Python 3.13.6:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r HomeAssignment/HA2/requirements.txt
.venv/bin/python HomeAssignment/HA2/sync.py --check
.venv/bin/python HomeAssignment/HA2/ha2_artifacts.py
.venv/bin/python HomeAssignment/HA2/ha2_artifacts.py --check
.venv/bin/python -m unittest discover -s HomeAssignment/HA2 -p 'test_ha2_*.py' -v
```

`ha2_artifacts.py` пересчитывает baseline → HA1 → perturbation → все
изображения → общий манифест. `--check` только проверяет файлы, без записи.
При изменении raw сначала выполнить `sync.py`, не `--refresh`: сеть и старая
Google-таблица не используются.

Альтернатива — **Run All** notebook в том же Python. Поддержаны рабочие
директории: корень репозитория, `HomeAssignment/HA2`, `Seminars/Class03`.
Notebook выполняет весь текущий комплект, а не только baseline.
Graphviz и сеть для вычислений/визуализации не нужны.

Низкоуровневые `ha2_analysis.py`, `ha2_coverage.py`, `ha2_perturbation.py`
остаются доступны по отдельности. Их запуск помечает общий комплект
требующим обновления; для согласованного результата использовать
`ha2_artifacts.py` или полный **Run All**.

## Формулы и области нормализации

- `is_a` направлено **parent → child**; только этот DAG используется для S.
  Полный типизированный граф — `MultiDiGraph`, сохраняющий параллельные типы.
- Глубины считаются от всех наблюдаемых корней; искусственного суперкорня нет.
  Сохраняются родители, корни, число путей и компоненты.
- Основные HA2-метрики:
  `S_depth = depth_min / max(depth_min)` и
  `S_breadth = 1 - ln(1 + descendants) / ln(1 + max_descendants)`.
  Потомки — различные достижимые узлы, не пути и не непосредственные дети.
- Основная нормировка глобальная по всем 44 узлам, а не по компонентам
  или только целевым. В эксперименте знаменатели пересчитываются по состояниям.
- Диапазоны глубин нормируются одним `max(depth_max)`; нижняя граница
  диапазона не обязана совпадать с `S_depth`.
- POS-оценки на индуцированных подграфах и противоречивая формула слайда 28
  `d + ln((1+n)/N)` сохранены как **диагностики**, не подменяющие две основные S.
  Сопоставление источников — в разделе 3 notebook.
- При N < 10 или нулевом знаменателе нормированные оценки не выдумываются:
  сохраняется NaN / пустое значение CSV. Сырые показатели остаются.
- **HA1 использует другую нормировку:** min–max C и кратчайшей глубины
  по 25 целевым. Порог ≥ 0.5 включается в «+».

## Проверенные числа

| Состояние | Узлы | Все рёбра / `is_a` | Компоненты | Корни | Изоляты |
|---|---:|---:|---:|---:|---:|
| Baseline | 44 | 41 / 37 | 9 | 15 | 0 |
| После +3 | 44 | 44 / 39 | 8 | 14 | 0 |
| После −3 | 44 | 41 / 36 | 11 | 17 | 2 |

В baseline максимумы кратчайшей/длиннейшей глубины — 5/5,
максимум потомков — 18, breadth-знаменатель — ln(19).
После +3: 5/6, 22, ln(23); после −3: 4/6, 18, ln(19).
Baseline имеет семь узлов с несколькими родителями, но вырожденные диапазоны.
В изменённых состояниях ненулевые диапазоны показаны в notebook и CSV.

HA1: квадранты **5 / 6 / 7 / 7**, нет пропусков S.
При `social=0` у «близости» — **5 / 5 / 7 / 8**.
Минимум три на квадрант выполнен в обоих сценариях, без изменения raw.

Perturbation последовательный: baseline → три добавления → три удаления
исходных рёбер. Относительно baseline порог `|Δ| > 0.1` превышен у трёх
целевых понятий по depth после добавлений; после удалений — у десяти по depth
и двух по breadth. Полный длинный формат содержит 264 разности и 39
отобранных строк для всех узлов. Вклад структуры отделён от смены знаменателя.

## Проверка и ограничения

Офлайн-тесты покрывают импорт, идентичности и POS, DAG, несколько корней,
диапазоны путей, distinct descendants, изоляты, разделение слоёв, HA1,
предусловия perturbation, строгий порог, идемпотентность и манифест всего комплекта.
Независимый stdlib-расчёт на BFS, явных root paths и множествах потомков
сверяет три состояния и 264 разности; отбор depth проверяется точными дробями.
Это не повторная семантическая экспертиза таксономии команды.

Наблюдаемые корни/потомки описывают выгрузку, не весь RuWordNet.
Изоляты после удаления имеют механические `S_depth=0`, `S_breadth=1`.
Нормированные значения зависят от глобальных знаменателей.
Размер 44 больше семинарского ориентира 15–25; в прямом перечне HA2
на слайде 33 отдельного ограничения нет, инвентарь не сокращался.
