# HA2 · Роль 2

Для роли 3 использовать `nodes.csv` и `edges.csv`. Определения и оценки признаков лежат в `raw/Concepts_hw2.csv`, источники в `raw/Sources.csv`. У целевых строк `node_id` совпадает с `concept_id`.

В графе 25 целевых и 31 вспомогательный узел, 50 рёбер `is_a` и три ручных ребра. `is_a` хранится в направлении `source -> target`, то есть родитель -> потомок. Только этот подграф используется для глубины и числа потомков. Для ручных рёбер направление читается по названию отношения. У «между», «над» и «внутри» таксономические рёбра отсутствуют.

## Изменения относительно выгрузки

- Объединены A24 с C01 (120377-N), A01 и A28 с C18 (106451-N). Источники C18 содержат несколько идентификаторов. Для иерархии использовано значение «место в пространстве» из HA1.
- Восстановлены семь рёбер из HA1 для веток места, границы и расстояния. Покрытие путей для новых синсетов зависит от выгрузки роли 1.
- Семь рёбер отложены, причины в `excluded_edges.csv`. Связь плоскости с наружной поверхностью тела смешивает смыслы. Для диаметра и радиуса в графе принят смысл отрезка.
- Ручные связи: координата задаёт положение точки, путь имеет конечные точки в смысле мест, диаметр проходит через центр.
- В текущем снимке по названиям 12 понятий из HA1 и 13 новых. Числа 16 + 9 из сообщения роли 1 требуют сверки.

## Синхронизация

Из корня репозитория запустить `python3 HomeAssignment/HA2/sync.py`. Флаг `--refresh` обновляет четыре CSV с Google Sheets. Локальные правки графа применяются при каждом запуске. Результат проверяется на совпадение целевого инвентаря, существование концов рёбер, дубликаты и циклы `is_a`.
